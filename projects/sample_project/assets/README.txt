Папка ассетов проекта.

Положите сюда спрайты (.png/.jpg), звуки (.wav/.ogg) и шрифты (.ttf).
Пути указываются относительно корня проекта, например:

    assets/player.png
    assets/jump.wav

Если файл текстуры не найден, Cloud Engine автоматически создаст
цветную заглушку, чтобы сцена всё равно отрисовалась.
