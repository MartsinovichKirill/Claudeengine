# Cloud Scripts

Cloud Scripts использует Python runtime и его стандартную библиотеку. Скрипты
исполняются с правами приложения: запускайте код, которому доверяете.
Отступ блока — четыре пробела. Комментарии начинаются с `#`.

## Объект и компоненты

```python
script CustomBehaviour extends Behaviour:
    export amount: float = 1.0

    on ready():
        print(self.game_object.name, self.amount)

    func set_amount(value: float):
        self.amount = value
```

Для новых объектов добавьте компонент ScriptBehaviour и выберите файл .cloud.
Behaviour — база скриптов компонентов; self.game_object возвращает владельца,
self.transform — его обязательный Transform. Несколько скриптов можно прикрепить
к одному объекту. Поля export редактируются отдельно у каждого компонента.
Для Python используйте `from engine.components.behaviour import Behaviour`.
Старые скрипты на основе Node2D и GameObject читаются для совместимости.
`func` объявляет функцию; у методов параметр self добавляется автоматически.

События: `on ready()`, `on process(delta)`, `on physics_process(delta)`,
`on input(event)`, `on enter_tree()`, `on exit_tree()`. Они соответствуют
методам движка с начальным `_`. Неизвестное имя события создаёт метод,
который нужно вызывать самостоятельно.

`export name: type = value` показывает поле в инспекторе. Типы: `int`, `float`,
`bool`, `str`, `Vector2`, `color`. Цвет задаётся кортежем RGBA.
Поля экземпляров копируются отдельно: списки разных персонажей не смешиваются.
`let` объявляет переменную. `const` запрещает повторное присваивание имени в том
же блоке функции/класса/модуля при компиляции; содержимое коллекции остаётся изменяемым.
Обычные Python-присваивания также работают. `true`, `false`, `null` — алиасы
`True`, `False`, `None`. Текст строк и комментариев не преобразуется.

## Выражения и управление

```python
const LIMIT = 10
func scores(values):
    let result = {}
    for index, value in enumerate(values):
        if value < 0:
            continue
        result[index] = min(value, LIMIT)
    return result

func load_config(path):
    import json
    try:
        with open(path, encoding="utf-8") as file:
            return json.load(file)
    except (OSError, ValueError) as error:
        print(error)
        return {}
```

Поддерживаются арифметика, сравнения, логические операции, срезы, списки,
словари, множества, кортежи, comprehensions, `while`, `break`, `continue`,
`try/except/finally`, `raise`, `with`, `yield`, декораторы, свойства и наследование.
`async/await` используют стандартный Python asyncio; автоматического планировщика
корутин в игровом цикле пока нет. Отдельного машинного компилятора и статического
анализатора типов нет; совместимость языка определяется установленным Python.

## Модули

Поместите `math_helpers.cloud` в `scripts/`:

```python
func clamp(value, low, high):
    return max(low, min(high, value))
```

В другом файле: `from math_helpers import clamp`. Поддерживаются и обычный
`import math_helpers`, и импорт Python-модулей/стандартной библиотеки.
Для вложенного файла `scripts/combat/damage.cloud` пишите
`from combat.damage import calculate`. Внутри вложенного модуля доступен
`from .helper import name`. Модули проекта кэшируются до перезагрузки скриптов.
Имена файлов должны быть допустимыми идентификаторами Python.

## Редактор и ошибки

Ctrl+Space открывает подсказки. `self.` учитывает базовый тип скрипта;
`self.position.`, `self.scale.` и `self.velocity.` показывают Vector2.
Свойства и функции имеют подсказки при наведении. F12 или Ctrl+щелчок
ищут определение в текущем файле и `.cloud`-файлах проекта, затем в API движка.
При переходе текущие изменения сохраняются. Ctrl+S сохраняет активный скрипт.
Синтаксис проверяется после ввода с указанием строки и столбца.
Ошибки выполнения и загрузки появляются в консоли редактора.

## Animator

Animator создаётся пустым. Добавьте собственные состояния, клипы и переходы,
укажите начальное состояние и параметры. В player_path укажите AnimationPlayer.
Переходы проверяются сверху вниз; * означает любое состояние.
`set_parameter(name, value)` меняет параметр, `trigger(name)` устанавливает
одноразовый флаг, который сбрасывается после проверки переходов.
Движок не добавляет готовые состояния или игровые правила.

## Экспорт игры

«Собрать EXE» экспортирует текущий проект отдельным проигрывателем без Qt,
редактора и хаба. Выберите имя, папку вне проекта, режим папки/одного EXE и
необязательную `.ico`-иконку. Размер, заголовок, полноэкранность, изменение размера,
иконка окна и стартовая сцена настраиваются в настройках проекта.
Все ресурсы включаются, кроме скрытых/служебных папок и символических ссылок.
Дополнительные Python-зависимости должны быть установлены в Python сборки;
динамические импорты через строки могут потребовать настройки сборщика вручную.
C# требует установленный .NET Framework на целевой Windows.
Ошибки игрового запуска записываются в `game-error.log` рядом с EXE.

## Полный практический маршрут: от проекта до игры

### 1. Создайте и запустите первый скрипт

1. В хабе создайте пустой проект. Откройте главную сцену. Добавьте объект с включённой Camera2D: без камеры Play не запускается.
2. Добавьте GameObject. У него уже есть Transform.
3. В ресурсах создайте `scripts/hello.cloud` через «Новый Cloud Script».
4. Вставьте пример ниже, сохраните файл и перезагрузите скрипты.
5. Добавьте объекту ScriptBehaviour и выберите этот файл. Нажмите Play.

```python
script Hello extends Behaviour:
    export message: string = "Hello, Cloud!"

    on enter_tree():
        print("Script entered the scene")

    on ready():
        print(self.message)

    on exit_tree():
        print("Script left the scene")
```

`enter_tree` вызывается перед `ready`, а `exit_tree` — при выгрузке экземпляра.
`process(delta)` вызывается каждый кадр. `physics_process(delta)` вызывается
с частотой физики проекта. `delta` измеряется в секундах. Движение, рассчитанное
через `delta`, не должно зависеть от частоты кадров.

### 2. Значения, типы и области видимости

```python
const MAX_COUNT = 20
let title = "Cloud"
let enabled = true
let absent = null
let position = Vector2(12, 40)
let names = ["first", "second"]
let options = {"volume": 0.8, "enabled": true}
```

`int` — целые числа, `float` — числа с дробной частью, `bool` — логические
значения, `str`/`string` — строки. `Vector2` содержит `x` и `y`. Для обычных
переменных аннотации являются подсказками; статической проверки типов нет.
Локальная переменная существует внутри функции. Поле класса читается через
`self.name`. Глобальная переменная принадлежит модулю.

`const` проверяет повторное присваивание простому имени при компиляции.
Это не глубокая неизменяемость: список внутри константы можно изменить.
Присваивание атрибутов через `self` и отражение не защищены этим механизмом.

### 3. Поля инспектора

```python
script Settings extends Behaviour:
    export speed: float = 120.0
    export count: int = 3
    export active: bool = true
    export caption: string = "Example"
    export direction: Vector2 = Vector2(1, 0)
    export tint: color = (255, 255, 255, 255)
    export texture: resource = "assets/example.png"
```

`resource` — строковый путь к ресурсу относительно проекта. Объявление не
загружает файл само по себе. Цвет имеет четыре канала 0–255: красный, зелёный,
синий и прозрачность. Поля родительского скрипта доступны в дочернем.
Каждый экземпляр получает собственные изменяемые значения полей.

### 4. Условия, циклы и функции

```python
func total_positive(values):
    let total = 0
    for value in values:
        if value <= 0:
            continue
        total += value
    return total

func countdown(count):
    while count > 0:
        print(count)
        count -= 1
```

Сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`. Логика: `and`, `or`, `not`.
Арифметика: `+`, `-`, `*`, `/`, `//`, `%`, `**`. `break` завершает цикл,
`continue` переходит к следующему шагу. Используйте `range(count)` для
фиксированного числа повторений. Бесконечный цикл в обработчике блокирует игру.
У методов `func` параметр `self` добавляется автоматически; у обычных функций
модуля этого не происходит. Аргументы, значения по умолчанию и `return`
работают по правилам Python.

### 5. Объект, Transform и соседние компоненты

```python
script Appearance extends Behaviour:
    export tint: color = (180, 220, 255, 255)

    on ready():
        let sprite = self.get_component("SpriteRenderer")
        if sprite is not null:
            sprite.color = self.tint
        self.transform.position = Vector2(100, 80)
        print(self.game_object.name)
```

`get_component` возвращает компонент или `None`. Сначала проверьте результат.
Названия типов API остаются английскими при любом языке интерфейса.
`self.game_object` — объект-владелец, `self.transform` — его Transform.
Позиция Transform локальна относительно родителя. Для мировой позиции
используйте `self.game_object.get_global_position()` и `set_global_position(value)`.

### 6. Физика без проваливания

Для падающего объекта добавьте **Rigidbody2D и BoxCollider2D**. Для неподвижного
пола достаточно **BoxCollider2D**. Убедитесь, что форма пола находится под
объектом, её размер соответствует картинке и слои/маски допускают столкновение.
SpriteRenderer рисует изображение, но не создаёт форму столкновения.

```python
script InitialImpulse extends Behaviour:
    export impulse: Vector2 = Vector2(100, -150)

    on ready():
        let body = self.get_component("Rigidbody2D")
        if body is not null:
            body.apply_impulse(self.impulse)
```

`velocity` задаётся в пикселях в секунду. `apply_impulse` мгновенно изменяет
скорость с учётом массы; `apply_force` прикладывает силу. `gravity_scale = 0`
отключает гравитацию для тела. `freeze` останавливает его интеграцию.
Не перемещайте физическое тело присваиванием Transform каждый кадр: это
телепортация, обходящая разрешение столкновений. Управляйте скоростью и силами.
Односторонний коллайдер пропускает снизу вверх и удерживает сверху.
Физика 2D движка не является полноценным решателем механических соединений.

### 7. Спрайты, кадры и тайлмап

У SpriteRenderer задайте `texture_path`. Для обычного спрайтшита задайте
`hframes`, `vframes` и `frame` (номер с нуля). `flip_h` и `flip_v` отражают
изображение; `sorting_order` меняет порядок отрисовки.

Через «Нарезать спрайт…» выберите сетку или ручные прямоугольники.
Сохранение создаёт рядом с исходником папку с его именем и отдельные PNG.
Файл `.sprites.json` содержит координаты областей. При повторном экспорте
измените префикс, если файлы уже существуют.

В палитре TileMap выберите «Добавить спрайты…» для отдельных PNG.
Для атласа используйте `tile_texture`, `tile_columns`, `tile_rows`.
Выберите тайл и включите «Коллизия (твёрдый тайл)», если он должен удерживать
физические объекты. Настройка сохраняется для этого тайла и обновляет уже
нарисованные клетки с тем же ID. Выбор другого тайла восстанавливает его флаг.
Декоративным тайлам коллизия не нужна. Размер картинки подгоняется под ячейку.

### 8. Сигналы

Компоненты предоставляют `connect`, `disconnect` и `emit_signal`.
Объявляйте собственные сигналы в скрипте и соединяйте их с методами:

```python
script Counter extends Behaviour:
    signal changed
    let value = 0

    on ready():
        self.connect("changed", self.report)
        self.value += 1
        self.emit_signal("changed", self.value)

    func report(value):
        print("Counter:", value)
```

Сигнал вызывается синхронно. Обработчик должен принимать переданные аргументы.
При подписке на долгоживущие внешние объекты отключайте подписку в `exit_tree`.
Сигналы столкновений не заменяют собственные проверки состояния игры.

### 9. Модули и наследование

В `scripts/base.cloud`:

```python
script Base extends Behaviour:
    export amount: float = 1.0

    func describe():
        return self.amount
```

В `scripts/custom.cloud`:

```python
from base import Base

script Custom extends Base:
    export label: string = "Custom"

    on ready():
        print(self.label, self.describe())
```

Избегайте циклического импорта: модуль, который ещё загружается, может не иметь
нужного класса. После изменения файла перезагрузите скрипты перед новым Play.
При изменении полей инспектора проверьте сохранённые значения сцены.

### 10. Ошибки и отладка

Сначала читайте первую ошибку консоли, имя файла и номер строки. Ошибка
`SyntaxError` обычно означает неверный отступ, пропущенное двоеточие или скобку.
`AttributeError` — неверное имя свойства либо компонент не найден.
`ImportError` — неверный путь модуля или отсутствующая зависимость.
`ZeroDivisionError` — деление на ноль. `TypeError` — несовместимые аргументы.

Поставьте точку остановки в редакторе и запустите Play. Используйте продолжение,
шаг с заходом и шаг с обходом; смотрите локальные переменные и стек вызовов.
Начинайте с небольшого скрипта и добавляйте по одному действию.

### 11. Async и Python-библиотеки

`async func` и `await` поддерживаются синтаксически. Корутина не начинает
выполняться от простого вызова; нужен планировщик asyncio. Игровой цикл не
планирует корутины автоматически. Не запускайте блокирующий `asyncio.run`
в обработчике кадра. Для первых проектов используйте обычные события.

Стандартные `math`, `json`, `random`, `pathlib` доступны через `import`.
Сторонняя библиотека должна входить в сборку. Не устанавливайте зависимости
во время запуска игры и не рассчитывайте на установленный Python пользователя.

### 12. Перенос на другой компьютер

Готовый редактор содержит встроенный Python runtime. Устанавливать Python
для запуска редактора и Cloud Scripts не требуется. Папочная сборка переносится
целиком вместе с `_internal`; однофайловая распаковывает runtime во временную
папку автоматически. Для самостоятельной пересборки из исходников нужен Python
с зависимостями. Экспорт новой игры использует инструменты сборки; это отдельная
операция от запуска уже собранного редактора или игры.

### Проверка перед экспортом

Сохраните сцену и скрипты, убедитесь в наличии стартовой сцены и ресурсов внутри
проекта. Запустите Play, проверьте коллизии и консоль. После экспорта тестируйте
игру из папки результата, а не из исходников. Проверяйте отдельно компьютер
без среды разработки: наличие локальных библиотек не должно маскировать
отсутствующие файлы сборки.

## Проверка скрипта перед запуском сцены

При Play редактор проверяет синтаксис сохранённых .cloud/.py файлов, прикреплённых к объектам и компонентам сцены. Код при проверке не исполняется. Ошибка содержит имя файла и сообщение компилятора; выбор строки выделяет объект. Сохраните скрипт перед проверкой. Ошибки импортов и исключения при выполнении проверяются отдельно во время Play. См. TILES_SCENE_CHECK.md.


## Ввод и исправление ошибок

InputEventKey содержит key и pressed. InputEventMouseButton содержит button,
pressed и position. Это объекты, а не словари; поля type и метод get у них
не предусмотрены. Для непрерывного движения используйте
self.get_tree().input.is_key_pressed("D") или настроенные действия ввода.
Скорость Rigidbody2D задаётся в пикселях в секунду и не умножается на delta.

Перед Play редактор сохраняет изменённый активный скрипт и проверяет синтаксис.
Лишний символ после выражения, например `Vector2(1, 0)в`, является ошибкой
исходного кода. Удалите символ, сохраните файл и повторите запуск.
Ошибка загрузки содержит путь и строку; двойной щелчок по строке File в
консоли открывает файл. Повторная загрузка без изменений не дублирует ту же
ошибку. Компонент ScriptBehaviour с ошибкой выполнения отключается в игровой
копии сцены до следующего запуска. Ошибка скрипта ноды останавливает Play.


## Переходы, звук, камеры и кат-сцены (beta.6)

```python
script LevelFlow extends Behaviour:
    on ready():
        tree = self.get_tree()
        tree.shared_data["score"] = tree.shared_data.get("score", 0)
        tree.audio_system.set_bus_volume("music", 0.7)

    func next_level():
        self.get_tree().load_scene("scenes/level2.scene")

    func start_intro():
        self.get_tree().cutscenes.play("intro.cutscene")

    func switch_camera():
        self.get_tree().set_camera("Camera2")
```

load_scene ставит переход в очередь конца кадра, shared_data живёт до завершения
игрового запуска. Обрабатывайте ошибки пути до следующего уровня. Кат-сцена
работает с существующими объектами текущей сцены. Для отключения управления
проверяйте `self.get_tree().cutscenes.playing` в логике персонажа.
Микшер: set_bus_volume(bus, 0..1), set_bus_mute(bus, bool),
fade_bus(bus, target_volume, seconds). Шины master/music/sfx/ui.

## AnimatedSprite2D и Parallax2D в beta.7

Нода AnimatedSprite2D поддерживает именованные клипы, созданные в окне анимаций:

```python
sprite = self.get_node('Visual')
sprite.play('Run')             # одинаковый клип не сбрасывается каждый кадр
sprite.play('Jump', restart=True)
sprite.speed_scale = 1.2
sprite.pause()
sprite.set_frame(0)
sprite.connect('animation_finished', self.on_animation_finished)
```

У обработчика animation_finished нет аргументов. Данные клипов находятся в sprite.animations: словарь вида {'Idle': {'frames': ['assets/idle_00.png'], 'fps': 7, 'loop': True}}. Для добавления из кода используйте sprite.add_animation('Idle', paths, fps=7, loop=True). Имена чувствительны к регистру. play с неизвестным именем сообщает об ошибке.

Parallax2D работает с дочерними нодами. Пример настройки: background.scroll_scale = Vector2(0.2, 0.2), background.autoscroll = Vector2(10, 0), background.repeat_size = Vector2(1024, 0). Эти настройки меняют изображение, но не мировые координаты и не коллизии.

CanvasLayer: hud.offset = Vector2(24, 20), hud.scale = Vector2(1, 1), hud.layer = 5. Координаты дочернего интерфейса экранные; движение камеры на них не влияет.


## Покадровые области атаки и уязвимости (beta.8)

В редакторе AnimatedSprite2D создайте Hit/Hurt области. Результат попадания — сигнал, а правила HP остаются в скрипте:

```python
script Player extends GameObject:
    func _ready():
        self.get_node('Visual').connect('hitbox_entered', self.on_hit)

    func on_hit(target_sprite, hit_id, hurt_id):
        # target_sprite — AnimatedSprite2D цели, а не её физическое тело.
        print('Попадание', hit_id, hurt_id, target_sprite.name)
```

Сигнал hurtbox_entered на цели получает (source_sprite, hit_id, hurt_id). Оба имеют три аргумента. get_active_hitboxes() возвращает текущие области с мировыми points (четыре Vector2). Проверка использует mask атаки & layer уязвимости, отражение, глобальные поворот/масштаб; не создаёт физические тела. Сохранение сцены сохраняет areas в animations[clip]['hitboxes'], где ключ кадра — строка индекса с нуля, rect — [x,y,width,height] в пикселях PNG. ID одной атаки следует сохранять между соседними активными кадрами.

## Звуковые и событийные дорожки кат-сцен (beta.8)

Создавайте дорожки в окне кат-сцен и запускайте сохранённый файл:

```python
self.get_tree().play_cutscene('cutscenes/intro.cutscene')
```

Событие вызывает публичный метод объекта/компонента один раз при достижении start; args — JSON-массив аргументов. Звуковая дорожка вызывает play на AudioStreamPlayer/AudioSource, затем stop по окончании start+duration. Предпросмотр редактора и seek не вызывают методы и звук. При смене сцены проигрыватель останавливается. Имена методов должны быть публичными, без начального подчёркивания.
